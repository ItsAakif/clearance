% Clearance LaTeX template: latex-medium-professional ("Medium Length Professional")
%
% REVIEWED MARKER, NOT THE RENDERED DOCUMENT.
%
% The document compiled at render time is generated per resume by
% backend/src/render/latexExport.ts with `variant: 'medium-professional'` and staged as
% `artifact.tex`. This file exists so the registry has a reviewed source to gate on,
% exactly as `template.typ` is for a Typst template, and so a template cannot enter the
% registry with no source at all.
%
% The fixed preamble and the closed macro set live in latexExport.ts, which is the ONE
% place a resume value becomes LaTeX source. This variant is an original Clearance
% implementation of the classic Trey Hunner / LaTeXTemplates "Medium Length Professional
% CV" look (letter paper, left-aligned uppercase name, uppercase ruled headings, tight hyphen
% bullets and hanging-indent skill lines); it copies no upstream class file.
